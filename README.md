# ScanSign

Document scanner web app with signature & stamp support and iOS Liquid Glass UI.

## Features

- Camera scan with document frame guide
- Import from photos / files
- **Draw signature** or **upload PNG signature**
- Built-in stamps + custom image stamps + text stamps
- Filters, rotate, text annotations, undo
- Export as **PNG** or **PDF**
- Fully client-side (nothing leaves your device)
- Customizable accent color, pen color/thickness, stamp size

## Repository

https://github.com/adamad2111/scansign

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import `adamad2111/scansign`
3. Framework: **Other** (static HTML)
4. Deploy

Or connect via the Vercel Git integration after authorizing the team.

## Local

Open `index.html` in a modern browser. Camera access requires HTTPS or localhost.
