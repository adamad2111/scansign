# ScanSign

Document scanner web app with signature and stamp support.

**Features**
- Camera scan + image import
- Draw or **upload PNG signature**
- Built-in + custom stamps
- Filters, rotate, text annotations
- Export PNG / PDF
- Fully client-side (no server)
- iOS Liquid Glass style UI

## Live

Deployed on Vercel (after setup).

## Local

Open `index.html` in a browser (camera needs HTTPS or localhost).
